Privacy Policy

Quick Add for Blitzit
Last updated: August 26, 2026

Quick Add for Blitzit is an unofficial Chrome extension that lets a user create tasks in the user's own Blitzit account through a Blitzit Incoming Webhook. It is not affiliated with or endorsed by Blitzit App Ltd.

1. Data handled by the extension

The extension handles only data needed for its task-creation purpose:

  • List Profile names, the selected default List, Default Schedule values, and shortcut assignments entered by the user;
  • the Blitzit Incoming Webhook URL and Signing Secret entered by the user;
  • task content entered by the user, including Title, Schedule, Date, Time, and optional Notes;
  • a randomly generated external task identifier used for each create request; and
  • limited response fields returned by Blitzit for the submitted request.

This version does not read browsing history, current-page URLs, page titles, page content, selected text, cookies, or other website data. It does not use a Content Script.

2. How data is used

List Profile settings and shortcut assignments are used locally to present and operate the extension. The Webhook URL and Signing Secret are used only to authenticate the task-create request chosen by the user. Task content is converted to the required Blitzit Webhook fields and sent to the configured Blitzit endpoint only when the user sends a task.

The extension does not use data for advertising, profiling, credit decisions, or any purpose unrelated to its task-creation function.

3. Storage and security

Ordinary profile settings are stored locally in Chrome extension storage. The Webhook URL and Signing Secret are encrypted locally with AES-GCM before their encrypted records are stored. The non-extractable encryption key is stored in the extension's IndexedDB database.

Credentials are entered in the extension's Options page and sent directly within the extension to its trusted Service Worker. Saved credentials are decrypted, destination-validated, and attached to authenticated requests only by the Service Worker. Authenticated requests are limited to HTTPS endpoints under https://webhook.blitzit.app/v1/inbound/, reject redirects, omit ambient browser credentials, and use a bounded timeout.

Task content is not retained as a separate local task history or ledger after submission.

4. Data sharing and transfers

Task content, the generated task identifier, and the authentication information required by the configured Incoming Webhook are transmitted directly from the extension to Blitzit over HTTPS. Blitzit receives and processes that data under its own terms and privacy practices.

No developer-operated server receives extension data. The extension does not sell user data or share it with advertising platforms or data brokers. The extension developer does not receive the data and does not allow developer personnel to read it.

5. Retention and deletion

Local settings and encrypted credential records remain in the extension's local storage until the user changes or deletes them. Deleting a List Profile removes its saved credential record. The Options page also provides a credential-vault reset that removes all saved Webhook credentials and the local encryption key; profile display settings remain so credentials can be re-entered.

Uninstalling the extension removes its extension-scoped local data according to Chrome's normal extension-storage behavior. Data already submitted to Blitzit is controlled through the user's Blitzit account and is not retained or deletable by this extension.

6. Chrome Web Store Limited Use

The extension's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used and transferred only as necessary to provide the extension's disclosed single purpose.

7. Changes and contact

If a future version changes its data handling, the disclosure and this policy will be updated before that change is distributed. Privacy or support questions can be submitted through the support channel shown on this extension's Chrome Web Store listing.
